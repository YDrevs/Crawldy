# Знімки для візуального огляду

Не документація й не артефакт збірки — матеріал для одного рішення:
чи прийнято візуальний напрям.

Знімаються Playwright'ом із піднятого dev-сервера:

```bash
cd backend
.venv/Scripts/python.exe scripts/shoot_ui.py http://localhost:3000 ../design-review
```

Два розміри навмисно. Десктоп — цільовий, мобільний — той, на якому
верстка ламається перша: німецьке «Geplante Audits» удвічі довше за
«Audits», а шапка на 390 пікселях не має місця на другий рядок.

Знімки в репозиторії лежать свідомо: структурна перевірка HTML не бачить
того, що видно оком. Кнопка в шапці була 98 пікселів заввишки замість
36 — `tsc`, `build` і читання дерева доступності про це мовчали.
