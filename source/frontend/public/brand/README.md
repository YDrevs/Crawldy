# Бренд-файли Crawldy

Оригінали дизайнера лежать поза репозиторієм
(`Desktop/Проекти/Crawldy/Logo/`). Тут — веб-версії без жодних змін
самого знака:

- `crawldy-horizontal.png` — горизонтальний локап дизайнера
  (оригінал `crawldy_horizontal.png` 4348×876 → 1600×322, LANCZOS).
- `crawldy-vertical.png` — вертикальний локап дизайнера
  (оригінал `crawldy_logo.png` 4427×2398 → 1000×542).
- `crawldy-mark.png`, `crawldy-wordmark.png` — точні вирізки з
  горизонтального файлу по найширшому прозорому проміжку (299px між
  знаком і написом), потім даунскейл. Жоден піксель знака не змінено.

Компоненти — `app/components/Brand.tsx`: `Logo` (горизонтальний,
шапки), `LogoStacked` (вертикальний, вхід/каса/порожні стани),
`Logomark`/`Wordmark` (вирізки для тісних місць).
